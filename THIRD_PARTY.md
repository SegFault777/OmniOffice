# Third-party material

## Google Material Symbols (icons)
- Source: https://github.com/google/material-design-icons (Material Symbols, Outlined, weight 400, 24px).
- License: Apache License 2.0, full text in `assets/material-symbols/LICENSE`. Apache-2.0 is compatible with this project's GPL-3.0-only.
- Use: SVG path data of ~47 icons is embedded in `crates/omni-shell/src/icons_data.rs`
  (generated by `tools/gen_icons.py`; that generated file keeps its `Apache-2.0` SPDX header). Icons are unmodified.

## Rust crates
Dependencies (winit, softbuffer, skia-safe, rfd, arboard, regex, miniz_oxide) are used under their own licenses
(MIT/Apache-2.0/BSD); run `cargo tree` for the list.
