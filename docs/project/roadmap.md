# Roadmap

- **1.0-alpha-1** (current): terminal editor, OMD/TXT/markup/DOCX, text import for ODF/HWPX/HML/ABW.
- 1.0-alpha-2: RTF, HWP v5 (OLE2 + inflate) import, ODT/HWPX export, find/replace, redo.
- 1.0-alpha-3: styles (headings, bold/italic) in OMD, outline pane, command palette, DOC import.
- 1.0-beta: native GUI back-ends without libraries (Win32 GDI, X11 wire protocol, macOS TBD).
- Later: PDF text import, WPD/WPS/LWP/WRI/CWK/PAGES/UOF, GUL/JUNG if specifications are found.
