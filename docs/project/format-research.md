# Format research

- HWP: Hancom binary format (OLE2 compound file; spec published by Hancom). HWPX: OWPML ZIP+XML.
  HML: Hancom XML. All three are used mainly in South Korea.
- GUL / JUNG: associated with JungUm Global (Samsung), a Korean word processor. Most .gul files
  are OLE2 compound files (magic `D0 CF 11 E0 A1 B1 1A E1`). No public specification was found,
  so no reader exists yet.
- WPD WordPerfect, WPS MS Works/Kingsoft, LWP Lotus Word Pro, WRI Windows Write, CWK ClarisWorks,
  SXW OpenOffice 1.x, ABW AbiWord, UOF Chinese Uniform Office Format, PAGES Apple Pages: legacy
  or regional word-processor formats; ABW and SXW are XML/ZIP and implemented first.
- TYP is Typst, ADOC is AsciiDoc, ORG is Org mode, WIKI is MediaWiki markup, GML/SGML are
  generalized markup languages.
