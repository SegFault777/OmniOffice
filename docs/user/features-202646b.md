# New in 202646b

## Convenience (OmniDoc)
1. **Context menu**: right-click. Different entries with and without a selection.
2. **Recent files**: File tab lists the last files; the list is shared across sessions.
3. **Autosave and recovery**: every 30 s while there are unsaved changes; restored on next start without arguments.
4. **Double/triple click**: select a word / a paragraph. The ribbon also scrolls with the mouse wheel.

## From Microsoft Word
5. **Format Painter** (Ctrl+Shift+C): pick up formatting, move the caret or selection, press again to apply.
6. **Change Case**: UPPERCASE, lowercase, Title Case, Sentence case (selection or word under the caret).
7. **Sort**: A-Z / Z-A on the selected paragraphs, or the whole document.
8. **Show Marks** (Ctrl+Shift+*): paragraph marks.

## From LibreOffice Writer
9. **AutoCorrect** (Review tab): (c) (r) (tm) -- ... -> 1/2, common typos, "i" -> "I", sentence capitals.
10. **Word Completion**: grey suggestion at the caret from words in the document; Enter accepts.
11. **Regular-expression find and replace**: Alt+R in the find bar; `$1` style groups in the replacement.
12. **Statistics** (Ctrl+Shift+G): words, characters with/without spaces, sentences, paragraphs, pages.

## Other apps
- **OmniCel**: grid, formula bar, formulas (+ - * / comparisons, SUM AVERAGE MIN MAX COUNT IF ABS ROUND, ranges), CSV and OMC.
- **OmniShow**: slide sorter, 16:9 editor, speaker notes, F5 slideshow, import the heading outline of any OmniDoc-readable file (Ctrl+I).
- **OmniOffice**: launcher; `omnioffice file.omc` opens the file in the matching app.
