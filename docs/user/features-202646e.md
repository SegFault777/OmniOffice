# New in 202646e

## OmniShow
Ribbon with Home (slides, layouts), Insert (text box, rectangle, ellipse, line), Design (5 themes), Transitions (fade, push, wipe, apply to all),
Slide Show, View (normal, slide sorter, notes, zoom). Quick access toolbar (customizable, saved per user), command search, status bar
(slide count, notes toggle, view buttons, zoom slider), undo/redo, slide reordering, slideshow animations.

## OmniDoc compatibility
DOCX: heading styles resolved through styles.xml (also localized names such as "제목 1" and custom styles based on headings), paragraph/character style
bold/italic, bullets and numbers from numbering.xml, tables (one row per paragraph), text boxes, tracked changes, hidden text, no duplicate text from
AlternateContent. DOCX export: A4 page setup, East-Asian default font, document properties.
DOC: Windows-1252 punctuation, multi-piece documents, tables, hyperlink fields. HWP 5.x: body text import. Page guides and "Page n of m".

## OmniCel
Undo/redo, Shift+arrows and mouse range selection, Ctrl+C/X/V with the system clipboard (tab-separated), Ctrl+A, icon toolbar.
