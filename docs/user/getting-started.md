# Getting started

Run `omnioffice` and pick an application (1, 2, 3), or run `omnidoc`, `omnicel`, `omnishow` directly, optionally with a file.

## OmniDoc
- Ribbon tabs: File, Home, Review, View; `Ctrl+F1` collapses the ribbon, the mouse wheel over it scrolls it.
- `Ctrl+Shift+P`: command palette. `Ctrl+F`: find bar (Enter next, Ctrl+Enter replace all, Tab field, Alt+R regex, Esc).
- `Ctrl+B/I/U`, `Ctrl+Alt+1..3`, `Ctrl+Z/Y`, `Ctrl+X/C/V` (Cmd on macOS), `F9` navigation, `F11` focus, `Ctrl+Shift+D` dark mode.
- Korean/Japanese/Chinese IME input works in all three apps.

## OmniCel
Click a cell and type; Enter/Tab/arrows commit and move; `F2` edits; `Del` clears; `=SUM(A1:A3)` formulas; `Ctrl+O/S`.

## OmniShow
`Ctrl+M` new slide, `Ctrl+D` duplicate, `Ctrl+Del` delete, Enter in a bullet adds another, `F5` slideshow, `Ctrl+O/S/I`.

Known limits: OmniDoc is one continuous page, no images/tables; OmniCel has no undo or copy/paste yet; OmniShow has text only.
