# Supported formats (0.2.0)

| Format | Read | Write | Fidelity |
|---|---|---|---|
| OMD | yes | yes | full (styles, alignment, bold/italic/underline) |
| DOCX | yes | yes | headings, alignment, bold/italic/underline |
| ODT | yes | yes | same as DOCX |
| RTF | yes | yes | text and run formatting; headings become bold text |
| MD | yes | yes | headings, quotes, code, bold/italic/underline (alignment lost) |
| TXT, HTML, XHTML, XML, LaTeX, RST, Org, Typst, MediaWiki, AsciiDoc, SGML, GML | yes | yes | edited as source text |
| DOCM, SXW, HWPX, HML, ABW | text only | no | |
| HWP, DOC, PDF, PAGES, WPD, WPS, LWP, WRI, CWK, UOF, GUL, JUNG | no | no | planned, see roadmap |
