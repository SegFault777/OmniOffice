# Supported formats (1.0-alpha-1)

| Format | Read | Write | Notes |
|---|---|---|---|
| OMD | yes | yes | native |
| TXT, MD, HTML, XHTML, XML, LaTeX, RST, Org, Typst, MediaWiki, AsciiDoc, SGML, GML | yes | yes | source-text editing, no rendering |
| DOCX | text | text | formatting is not preserved |
| DOCM, ODT, SXW, HWPX | text | no | ZIP + XML text extraction |
| HML, ABW | text | no | XML text extraction |
| RTF, DOC, PDF, HWP, PAGES, WPD, WPS, LWP, WRI, CWK, UOF | no | no | planned |
| GUL, JUNG | no | no | JungUm Global (Samsung) OLE2 documents; see `docs/project/format-research.md` |
